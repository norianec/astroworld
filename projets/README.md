# Projets

Un dossier par création, nommé avec la date puis un nom court :

```
projets/
└── 2026-10-12-reel-routine-matin/
    ├── rushs/      ← tes vidéos brutes filmées au téléphone
    ├── export/     ← la vidéo finale prête à poster
    └── script.md   ← le texte / script (créé par Claude)
```

Tu peux simplement dire à Claude : *« Crée un nouveau projet pour mon Reel sur ma routine du matin »*
et il prépare le dossier.

Les fichiers vidéo (`.mp4`, `.mov`…) restent sur ton ordinateur : ils ne sont **pas**
envoyés sur GitHub, car trop lourds. Pense à les sauvegarder ailleurs (disque dur, cloud).
