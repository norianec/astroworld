# Vidéo : « Qu'est-ce qui retient notre air ? »

Vidéo verticale (9:16) d'environ 70 secondes + signature AstroNori à la fin.

| Fichier | Rôle |
|---|---|
| `script.md` | Le script adapté (version 1 minute), scène par scène, avec les expressions d'AstroNori |
| `script-original.md` | Ton script d'origine, intact |
| `index.html` | La vidéo elle-même (3D + animations + sous-titres), fabriquée avec HyperFrames |
| `assets/perso/` | Ton personnage détouré, 9 expressions |
| `assets/textures/` | Textures de la Terre (three.js, domaine public NASA) et de Mars (Solar System Scope, CC BY 4.0) |
| `assets/voix/` | Voix off (voix IA locale « Siwis », française, gratuite) et minutage mot par mot |
| `assets/audio/` | Musique d'ambiance et petits effets sonores (créés sur mesure) |
| `renders/` | La vidéo finale (gardée sur l'ordinateur, pas sur GitHub) |

Pour refaire le rendu : `npm run render` dans ce dossier (ou demande à Claude).
